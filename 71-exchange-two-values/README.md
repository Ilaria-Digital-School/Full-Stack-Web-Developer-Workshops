# Exchange two values

**Theoretical Recap** A variable is a named container that holds a value at a given moment in a program's execution. You have already practiced declaring and assigning variables, as well as performing basic arithmetic expressions. Now, a classic and fundamental challenge in algorithmics is: how do you swap the values held by two variables? It sounds trivial, but it reveals a critical thinking trap that catches almost every beginner. If you have variable A = 5 and variable B = 10, and you write A = B, then A becomes 10 — but you have permanently lost the original value of A. You can no longer set B = A to get 5, because A is now 10. The solution is to use a third, temporary variable: you store A's original value in a temporary holder before overwriting A. This is called the three-step swap: (1) temp = A, (2) A = B, (3) B = temp. After these three steps, A holds 10 and B holds 5, which is exactly what we wanted. A common mistake is skipping the temporary variable and attempting a direct assignment, which always results in data loss. Another frequent error is confusing the order of the three steps. Always think of it as: save, overwrite, restore. This mental model applies universally, regardless of the programming language you will later use. --- **Workshop Brief** This workshop directly follows your work on variables, assignment, and arithmetic expressions.
