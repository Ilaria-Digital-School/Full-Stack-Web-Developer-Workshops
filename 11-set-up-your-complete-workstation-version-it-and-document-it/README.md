# Set up your complete workstation, version it and document it

Recap: the tools you already have in hand Your workstation is the set of tools you use every day. It includes an operating system, a terminal for typing commands, a code editor with its integrated terminal, a browser for inspecting web pages, and Git for keeping the history of your work. Git records snapshots called commits. Each commit has an identifier, an author, a date and a message. The mental model has three zones. The working folder is where you edit files. The staging area is where git add places the changes you select. The repository is where git commit stores those changes permanently. Beginners often make the same mistakes. They forget git add before committing, or write vague messages such as 'update'. They run Git from the wrong folder, or never check git status. Another trap is believing a file is saved in Git when you only saved it in the editor. Here is a mini example. Your folder contains 4 files. You modify 2 of them and create 1 new file. git status lists 2 modified files and 1 untracked file. You run git add on all 3, then git commit with the message 'Add notes on terminal commands'. If git log --oneline showed 3 lines before, it now shows 4.
