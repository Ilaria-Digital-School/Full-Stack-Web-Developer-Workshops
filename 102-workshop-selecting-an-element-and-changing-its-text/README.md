# Workshop: selecting an element and changing its text

THEORETICAL RECAP The DOM (Document Object Model) is the tree-like representation of your HTML page that the browser builds in memory. JavaScript can read and modify this tree in real time. To act on a specific element, you first need to select it, then read or change its content. The mental model is simple: think of the page as a family tree of nodes, where each HTML tag is a node you can reach and manipulate. To select an element, the most common modern methods are 'document.querySelector(selector)', which returns the first element matching a CSS selector (for example '#title', '.message', 'h1'), and 'document.getElementById(id)', which targets an element by its 'id'. Once you hold a reference to an element, you change its text with the 'textContent' property. Example: const titre = document.querySelector('#titre'); titre.textContent = 'New title'; Common mistakes to avoid: running your script before the element exists in the page (place your at the end of , or use a load event), confusing 'textContent' (raw text) with 'innerHTML' (interpreted HTML), and forgetting the '#' for an id or '.' for a class in querySelector. Also, 'querySelector' returns 'null' when nothing matches, which causes an error when you then try to change '.textContent'. Always verify your selector matches an existing element. This recap bridges the previous DOM lesson and today's hands-on practice.
