# Mini-project - Calculating the price of a train ticket

THEORETICAL RECAP A program is a sequence of instructions executed in order. To build useful logic, you combine three foundations you have already studied: variables (containers that store data such as numbers, strings or booleans), conditions (IF / ELSE IF / ELSE structures that let the program choose a path depending on a situation), and comparison and logical operators. Comparison operators (==, !=, , =) produce a boolean (true or false). Logical operators combine several booleans: AND (both conditions must be true), OR (at least one must be true), NOT (inverts a boolean). Mental model: think of your program as a decision tree. At each branch, you ask a yes/no question, and the answer routes you toward the correct calculation. A price calculator is exactly this: a base value that gets modified by a series of conditional rules. Common mistakes: confusing = (assignment) with == (comparison); forgetting the ELSE branch and leaving a case unhandled; chaining conditions in the wrong order so that a broad rule captures a case before a specific rule can apply; and mixing AND/OR without understanding priority. Mini example: age = 12 price = 20 IF age < 13 THEN price = price * 0.5 Here the condition age < 13 is true, so price becomes 10. Notice that the discount is applied only when the boolean is true.
