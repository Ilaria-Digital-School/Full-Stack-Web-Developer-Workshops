# Full-Stack Developer

Become a full-stack developer, from scratch to bachelor's degree level: design, develop, secure, test and deploy web and mobile applications. Skills: Understand how computers, operating systems and networks work; Program in JavaScript and Python, using object-oriented programming; Analyse a need and design a system (data modelling, mockups, UML); Design and query SQL and NoSQL databases; Develop accessible web interfaces with HTML, CSS and Angular; Develop REST APIs with Node and Express; Secure a web application; Test, containerise and deploy with continuous integration; Design a multi-layer software architecture; Administer networks and databases; Analyse data with Python; Manage an IT project using agile methods; Comply with digital law and ethics. Workshops are based on exercises and on the projects you build throughout the programme, including your online shop; the data you need is provided.

[View the full workshop](https://www.ilaria-academy.com/nextjob/full-stack-web-developer/en/)
