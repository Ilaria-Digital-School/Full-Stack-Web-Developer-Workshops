# Browse a list and view items

THEORETICAL RECAP A list (also called an array or table) is an ordered collection of values stored under a single name, where each element occupies a position identified by an index. In most programming languages, indexing starts at 0: the first element is at index 0, the second at index 1, and so on. Browsing (or traversing) a list means visiting each element one after another, usually to read, display, or process it. The key mental model: imagine a row of numbered lockers. The list is the row, each locker holds a value, and the index is the locker number. To go through all lockers, you use a loop. A 'for' loop is the natural tool: it moves through each position automatically. A 'while' loop works too, but you must manage the counter yourself. Common mistakes: (1) starting at index 1 instead of 0, which skips the first element; (2) the off-by-one error, looping one step too far and trying to access an index that does not exist (out of bounds); (3) confusing the index (position) with the value (content); (4) forgetting to increment the counter in a while loop, causing an infinite loop. Mini example (pseudocode): fruits = ["apple", "banana", "cherry"] for i from 0 to length(fruits) - 1: display(fruits[i]) This prints each fruit on its own line.
