# Workshop: mini calculator in console

THEORETICAL RECAP Before starting, let's consolidate what you already know. In JavaScript ES6, you declare variables with `let` (reassignable) and `const` (fixed reference). Primitive types include numbers, strings, and booleans. A crucial point for a calculator: data collected from the console arrives as strings, not numbers. This is where type conversion matters. Use `Number(value)`, `parseInt(value)`, or `parseFloat(value)` to transform text into a usable number. A common mistake is forgetting this step: `"5" + "3"` gives `"53"` (string concatenation), while `Number("5") + Number("3")` gives `8`. Mental model: think of your program as a pipeline. Input (raw text) enters, gets converted (text to number), gets processed (arithmetic operation), and produces output (a result displayed to the user). Each stage must be clean before moving to the next. Arithmetic operators (`+`, `-`, `*`, `/`, `%`) work on numbers. Template literals (using backticks and `${}`) let you build readable output messages, for example: `console.log(\`The result is: ${result}\`)`. Another frequent error is dividing by zero, which yields `Infinity` in JavaScript rather than an error, so anticipate it. Mini example: ``` const a = Number(prompt("First number:")); const b = Number(prompt("Second number:")); console.log(`Sum: ${a + b}`); ``` Keep this pipeline logic in mind throughout the workshop.
