# Declare and assign variables

THEORETICAL RECAP A variable is a named container that stores a value in memory during the execution of a program. Think of it as a labeled box: you give it a name, you put something inside, and you can open it, read its content, or replace it at any time. Declaring a variable means reserving a space in memory and giving it a name. Assigning a variable means placing a value inside that space. These are two distinct operations, though they are often combined in a single instruction. In pseudocode, declaration and assignment typically look like this: DECLARE age AS INTEGER, then age
