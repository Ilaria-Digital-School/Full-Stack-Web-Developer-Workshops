# Build a navigation bar with Flexbox

Recap: Flexbox for Navigation Flexbox is a CSS layout module designed for distributing space and aligning items within a container, especially when their sizes are unknown or dynamic. It provides a one-dimensional layout model that makes it efficient to handle alignment, distribution, and ordering of elements along a single axis. The core mental model involves a parent container (the flex container) and its direct children (flex items). When you apply `display: flex` to a container, it creates this context, allowing you to control the direction of the main axis with `flex-direction` and the alignment along that axis with `justify-content`. A common mistake is applying flex properties directly to flex items before configuring the container. Always start by defining the container's behavior. Another frequent error is mixing flex properties intended for the container, like `justify-content`, with those for items, like `align-self`, leading to unexpected results. For instance, vertical centering requires you to understand both the main and cross axes. A small example: a container with `display: flex; justify-content: space-between; align-items: center;` will evenly distribute its child items horizontally while centering them vertically. Your recent lessons on the box model, display types, and positioning provide the foundation. Remember, flex items are laid out along the main axis, which can be row or column. Understanding how `flex-direction` changes this axis is crucial for responsive designs.
