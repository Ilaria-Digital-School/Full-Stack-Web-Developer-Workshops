# Checkpoint ramp - Simple shopping cart management

## Project Overview This mini-project is a skills validation checkpoint designed to consolidate everything you have learned so far in the 'Algorithmics and programming logic' chapter. Building directly on your work with variables, data types, constants, naming conventions, and basic calculations (including your BMI project), you will now design and implement a simple shopping cart management system. The context is realistic and professional: any e-commerce application requires the ability to manage a list of products, calculate totals, apply discounts, and display a clear summary. This project places you in that role. --- ## What You Will Build You will write a program (in the language introduced in the course: pseudocode and/or a real language such as Python or JavaScript, as specified by your instructor) that simulates the core logic of a shopping cart. The program must: 1. **Store product information** using clearly named variables and constants (product names, unit prices, quantities). 2. **Handle multiple data types** correctly: strings for product names, integers for quantities, floats/reals for prices and totals, booleans for discount eligibility. 3. **Perform calculations**: line totals (price × quantity), cart subtotal, discount application, and final total including tax. 4. **Apply a discount** using a constant (e.g., DISCOUNT_RATE = 0.10 for 10%) when a condition is met (e.g., subtotal exceeds a threshold). 5. **Display a formatted cart summary** showing each product line, subtotal, discount amount (if applicable), tax amount, and grand total. --- ## Skills Validated - Declaring, naming, and assigning variables following conventions (camelCase or snake_case as appropriate)....
