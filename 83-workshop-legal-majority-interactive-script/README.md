# Workshop: legal majority — interactive script

THEORETICAL RECAP In JavaScript ES6+, a program often needs to react to information provided at runtime. You have already seen variables (let, const), primitive types (number, string, boolean), type conversions, arithmetic operators, template literals, and if/else conditions with comparison operators. This workshop combines all of these. Mental model: think of your script as a small decision machine. It receives an input (an age), transforms it into the correct type, compares it against a rule (the legal majority threshold of 18), and produces a personalized message. Input arrives as text, so it must be converted before any numeric comparison. Key definitions: prompt() reads a value from the user and always returns a string. Number() or parseInt() convert that string into a number. A comparison operator like >= returns a boolean. An if/else block chooses which branch of code runs based on that boolean. Common mistakes: comparing a string to a number without converting ("18" >= 18 works by coercion, but relying on this is fragile); forgetting that empty or non-numeric input produces NaN; using = (assignment) instead of === (strict comparison); and concatenating messages with + instead of using cleaner template literals. Mini example: const ageText = prompt('Your age?'); const age = Number(ageText); if (age >= 18) { console.log(`You are of legal age (${age}).`); } else { console.log(`You are a minor (${age}).`); } This is the exact foundation you will extend below.
