# Style your three-page personal website

Recap the CSS tools you will combine Your stylesheet is a set of rules that cascade. A rule placed on body is inherited by every page that links the same style.css, so one external file gives you three consistent pages. In the previous activities you used position: fixed to pin a bar, :hover and :focus-visible to show states, and Flexbox to align and wrap items. Keep one mental model in mind. An element with position: fixed leaves the normal flow, so the rest of the page slides up underneath it. This is why a fixed bar often hides the first heading. If your bar is 64 px tall, give the body a padding-top of 64 px. Three mistakes come up often. The first is removing the outline without replacing it, which leaves keyboard users without a visible focus. The second is using fixed pixel widths that overflow on small screens. The third is loading several fonts and weights for one simple page. Here is a mini example. A card container with a maximum width of 960 px and gap: 16px holds cards set to flex: 1 1 250px. Three cards need 250 × 3 + 16 × 2 = 782 px, so three fit on one line, while four would need 1,048 px and the fourth wraps.
