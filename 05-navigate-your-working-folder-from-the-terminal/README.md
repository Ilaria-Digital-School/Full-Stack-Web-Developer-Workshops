# Navigate your working folder from the terminal

Core Terminal Concepts Recap Your terminal is a text-based interface to your computer's operating system. It allows you to execute commands to manipulate files, directories, and programs directly. The current directory you are working in is called the working directory. Navigating this structure is fundamental, as all your development files will be organized within folders. A common mental model is the file system tree. The root is the top-most directory, and all other folders branch out from it. Your working folder is a specific point on this tree. The `pwd` command prints your current location. The `ls` command lists the contents of the working directory. The `cd` command changes your working directory. Beginners often confuse relative and absolute paths. An absolute path starts from the root, like `/Users/YourName/Projects`. A relative path starts from your current location, like `../Documents`. Another common mistake is forgetting that folder names are case-sensitive on macOS and Linux. For a small example, if your folder contains 3 files, `ls` will list them as `1.txt`, `2.txt`, `3.txt`.
