# Identify tags, elements and attributes in a code snippet

Theoretical Recap Let's establish the mental model for HTML coding. HTML is a markup language built from three core components: tags, elements, and attributes. A tag is a keyword surrounded by angle brackets, like `` for a paragraph. Tags come in pairs: an opening tag (e.g., ` `). An HTML element is the entire construct from the opening tag to the closing tag, including the content in between. For instance, ` ` is a complete heading element. An attribute provides additional information about an element and is always placed inside the opening tag. Attributes come in name-value pairs, like `src="image.jpg"` inside an `` tag. A common mistake is forgetting the closing tag or using incorrect nesting, such as `text`. This breaks the document structure. Another error is omitting quotation marks around attribute values. Always write `href="https://example.com"`, not `href=https://example.com`. A mini example is `Click me`. Here, `` is the tag, the whole line is the anchor element, and `href="#"` is an attribute.
