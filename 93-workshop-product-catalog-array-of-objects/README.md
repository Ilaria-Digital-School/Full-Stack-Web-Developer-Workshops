# Workshop: Product catalog (array of objects)

THEORETICAL RECAP An array of objects is simply an array whose elements are literal objects. It is the fundamental structure used to represent a collection of records: a list of products, users, orders, and so on. Each object holds properties (key/value pairs) describing one entity, and the array groups these entities so you can iterate over them. Mentally, picture a spreadsheet: each row is an object, each column is a property key shared by all objects. Example: const catalog = [ { id: 1, name: 'Keyboard', price: 45, category: 'peripherals', inStock: true }, { id: 2, name: 'Mouse', price: 25, category: 'peripherals', inStock: false } ]; You access data by combining iteration and property access: catalog.forEach(p => console.log(p.name, p.price)). To transform or select data, you rely on the array methods you already studied: map returns a new array of derived values, filter returns a subset matching a condition, and reduce collapses the array into a single value (a total, an average, a grouping). Common mistakes to avoid: forgetting that map/filter return a NEW array and do not mutate the original; confusing map (transform) with filter (select); accessing an undefined property (typo in the key) which silently returns undefined; and mutating objects inside a loop when you meant to build a new structure. Prefer const for your catalog and use pure, non-mutating operations when producing derived results.
