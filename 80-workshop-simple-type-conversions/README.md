# Workshop: Simple type conversions

THEORETICAL RECAP In JavaScript, every value has a type: string, number, boolean, undefined, null, and others. Type conversion (or type casting) means transforming a value from one type into another. There are two kinds. Explicit conversion is when you deliberately convert a value using functions like Number(), String(), Boolean(), parseInt(), or parseFloat(). Implicit conversion (coercion) happens automatically when JavaScript tries to reconcile mismatched types, for example when you use '+' between a string and a number. Mental model: think of each value as an object wearing a 'type label'. Conversion swaps that label and sometimes reshapes the content. For instance, Number('42') returns the number 42, while String(42) returns the string '42'. The value Boolean('') is false, but Boolean('false') is true because any non-empty string is truthy. Common mistakes: confusing '==' (loose, coerces types) with '===' (strict, no coercion); expecting '5' + 2 to equal 7 (it returns '52' because '+' concatenates when a string is involved); forgetting that Number('abc') returns NaN, not an error; and assuming parseInt('12px') fails (it actually returns 12). Mini example: let age = '30'; console.log(typeof age); // 'string' let ageNumber = Number(age); console.log(typeof ageNumber); // 'number' console.log(ageNumber + 5); // 35 Keep this recap open as a reference while you work.
