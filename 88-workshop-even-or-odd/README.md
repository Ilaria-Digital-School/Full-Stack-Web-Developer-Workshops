# Workshop: Even or odd?

THEORETICAL RECAP Determining whether a number is even or odd relies on the modulo operator (%), which returns the remainder of a division. A number is even when dividing it by 2 leaves no remainder, meaning n % 2 === 0. Otherwise, the remainder is 1 (or -1 for negatives), and the number is odd. This single operator is the mental model to keep: modulo answers 'what is left over after I divide?'. If nothing is left over by 2, the number is even. Remember the concepts you have already practiced: you declare variables with let and const, you read input from the console (or convert strings to numbers), and you branch decisions with if/else. Since user input often arrives as a string, you must convert it to a number with Number() or parseInt() before applying modulo — this is the single most common mistake beginners make. A second frequent error is confusing = (assignment), == (loose comparison), and === (strict comparison); always use === when testing the remainder. Mini example: const n = 7; if (n % 2 === 0) { console.log(`${n} is even`); } else { console.log(`${n} is odd`); } This prints '7 is odd'. With this pattern mastered, you are ready to build a small program that reliably classifies any number.
