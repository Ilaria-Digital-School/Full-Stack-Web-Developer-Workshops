# Create an image gallery with Grid

Theoretical Recap CSS Grid Layout provides a two-dimensional grid system for designing web layouts. A grid is defined on a parent container, turning it into a grid container. Its direct children become grid items arranged within rows and columns that you can explicitly define. A clear mental model is to think of the grid as intersecting horizontal and vertical lines that form tracks (the space between two lines). You place items into the cells these tracks create. The key properties are `display: grid` on the container, `grid-template-columns` and `grid-template-rows` to define the track sizes, and `gap` to control gutters. Common mistakes include forgetting to set display to grid, confusing the order of fr units, and trying to control everything with too many media queries. A powerful feature of Grid is its ability to create responsive layouts using functions like `repeat()`, `minmax()`, and flexible fr units, often reducing the need for breakpoints. Consider this mini example: `.gallery { display: grid; grid-template-columns: repeat(auto-fit, minmax(200px, 1fr)); gap: 1rem; }`. This creates columns that automatically fit the container, each at least 200px wide, stretching equally with spare space. It results in a basic responsive gallery without a single media query.
