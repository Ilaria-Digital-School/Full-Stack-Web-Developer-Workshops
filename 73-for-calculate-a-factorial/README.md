# For - Calculate a factorial

THEORETICAL RECAP A factorial of a non-negative integer N, written N!, is the product of all positive integers from 1 up to N. For example, 5! = 5 × 4 × 3 × 2 × 1 = 120. By convention, 0! = 1. This is a perfect problem for the 'for' loop, because you know in advance how many iterations you need: exactly N. The mental model is simple: start with an accumulator variable holding the value 1, then loop through each integer from 1 to N (inclusive) and multiply the accumulator by the current number at each step. After the loop finishes, the accumulator holds the factorial. This is the classic 'accumulator' pattern you saw in 'Common loop patterns', applied to multiplication instead of addition. A minimal example in pseudocode: result = 1 for i from 1 to N: result = result * i return result Common mistakes to avoid: initializing the accumulator to 0 (any multiplication then stays 0), forgetting to include N itself by stopping the loop one step too early (off-by-one error), and not handling the special case N = 0. Also watch loop boundaries carefully: many languages use ranges that exclude the upper bound, so you may need to loop up to N+1 to include N. --- WORKSHOP BRIEF Your goal in this workshop is to write a program that calculates the factorial of a number using a 'for' loop, and to prove that your solution is correct and robust.
