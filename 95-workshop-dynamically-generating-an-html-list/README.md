# Workshop: dynamically generating an HTML list

THEORETICAL RECAP Dynamically generating HTML means creating page elements with JavaScript instead of writing them by hand in your HTML file. This is the core of any modern web interface: you receive data (often an array of objects) and you transform it into visible DOM elements. The mental model is simple: think of your JavaScript as a factory that reads data on one side and produces DOM nodes on the other, then attaches them to the page. The essential tools you already saw: 'document.createElement(tag)' to build a new element, 'element.textContent' to set its text safely, 'element.appendChild(child)' or 'element.append(...)' to insert it, and 'document.querySelector(selector)' to grab the container where everything will live. To process an array, 'forEach' is your friend: you loop over each item and create one list element per item. Common mistakes to avoid: using 'innerHTML' with raw user data (a security risk and error-prone); forgetting to append the created element to the DOM (nothing appears); running your script before the DOM is loaded; and clearing the container incorrectly when re-rendering. A safe way to empty a container is 'container.innerHTML = ""' before regenerating. Mini example: const ul = document.querySelector('#list'); const fruits = ['Apple', 'Pear', 'Kiwi']; fruits.forEach(fruit => { const li = document.createElement('li'); li.textContent = fruit; ul.appendChild(li); }); This reads an array and produces one per item.
