# mini-project - BMI calculation

THEORETICAL RECAP Before diving into this workshop, let's consolidate what you have learned so far. A variable is a named storage location in memory that holds a value which can change during program execution. A constant, by contrast, holds a fixed value that should never be modified once defined — by convention, constants are written in UPPERCASE (e.g., MAX_SIZE). Data types matter: an integer (int) stores whole numbers, a real (float) stores decimal numbers, a string (str) stores text, and a boolean (bool) stores True or False. When performing arithmetic operations, be careful about type compatibility: dividing two integers may behave differently depending on the language, and mixing types without explicit conversion can cause bugs. A common mistake is forgetting to convert user input (which is always a string by default) into a numeric type before performing calculations. For example: height = float(input('Enter your height in meters: ')) ensures you can multiply or divide the value correctly. Always name your variables descriptively (bmi, weight_kg, height_m) and your constants clearly (BMI_OBESITY_THRESHOLD = 30.0). A clear mental model: think of your program as a recipe — you gather ingredients (inputs), process them (calculations), and present a result (output).
