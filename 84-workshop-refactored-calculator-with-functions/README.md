# Workshop: refactored calculator with functions

THEORETICAL RECAP A function is a reusable block of code that takes input (parameters), performs a task, and usually returns a value with the 'return' keyword. In ES6, you can declare functions in several ways: the classic declaration 'function add(a, b) { return a + b; }' or the arrow syntax 'const add = (a, b) => a + b;'. Arrow functions are concise and are ideal for short, single-purpose operations. The mental model to keep: a function is a small machine — you feed it inputs, it processes them, and it hands you back a result. A well-designed function does ONE thing and does it well (single responsibility). This makes your code easier to read, test, and reuse. Common mistakes to avoid: forgetting the 'return' statement (the function then returns 'undefined'); confusing displaying a value with 'console.log' and actually returning it; mixing calculation logic with user interaction inside the same function; and not handling edge cases such as division by zero. Mini example: const multiply = (a, b) => a * b; const result = multiply(6, 7); // 42 console.log(result); Here the calculation and the display are separated: 'multiply' only computes, and 'console.log' only shows. This separation is exactly what you will apply when refactoring a calculator. WORKSHOP BRIEF You have already built a mini calculator in the console during a previous workshop.
