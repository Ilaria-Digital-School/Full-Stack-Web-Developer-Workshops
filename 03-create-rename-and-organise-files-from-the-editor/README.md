# Create, rename and organise files from the editor

Theoretical recap A program is a set of instructions written for a computer. In practice, these instructions are stored in files. Your code editor is your primary workspace for creating and managing these files as a developer. The mental model is straightforward: files are containers for your code, folders are containers for related files, and your editor provides the interface to work with them. This structure is called a directory tree, where paths describe locations. Common mistakes include placing files directly on the desktop, creating overly deep folder structures, or using spaces in file names. A clear naming convention avoids confusion. For example, a small project might have three files: index.html, style.css, and script.js. These files would reside in a folder named 'my_project'. The path might be 'Documents/code/my_project'. This hierarchical organization is fundamental to managing complexity as your projects grow. Workshop brief This workshop puts those concepts into practice directly within Visual Studio Code. Your goal is to create a realistic folder and file structure for a simple web page project. You will work inside your designated working directory. The task is not just to create files, but to logically organise them. Think about which files belong together. Consider how you would navigate this structure later when looking for specific code. You will be assessed on your ability to translate an abstract plan into a concrete, organised file system.
