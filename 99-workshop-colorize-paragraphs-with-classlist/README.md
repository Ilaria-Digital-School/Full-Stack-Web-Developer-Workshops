# Workshop: Colorize paragraphs with ClassList

THEORETICAL RECAP The DOM lets you select and manipulate HTML elements from JavaScript. In the previous chapters you learned to select elements with document.querySelector and document.querySelectorAll, and to change their content. Now we focus on styling elements dynamically through the classList API instead of writing inline styles by hand. Every DOM element exposes a classList property, which is a live collection of that element's CSS classes with four key methods: add('name') adds a class, remove('name') removes it, toggle('name') adds it if absent or removes it if present, and contains('name') returns a boolean. The correct mental model is: your visual styles live in CSS classes, and JavaScript only decides which classes are attached to which elements. You never hardcode colors in JS; you define a class like .highlight { background-color: yellow; } in CSS and add it via element.classList.add('highlight'). Common mistakes: writing element.className = 'highlight' (this erases all existing classes), including the dot when calling classList methods (write 'highlight', not '.highlight'), and forgetting that querySelectorAll returns a NodeList you must loop over, not a single element. Mini example: const p = document.querySelector('p'); p.classList.add('highlight'); This single line attaches the CSS class, and the browser applies the styling instantly.
