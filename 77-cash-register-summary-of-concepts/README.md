# Cash register - summary of concepts

## Project overview You will build a command-line cash register program that simulates a real point-of-sale checkout. This mini-project consolidates every core concept you have practiced in the Algorithmics and programming logic chapter: functions, parameter passing and variable scope, loops, lists, searching values in a list, and clean code documentation. The program manages a small catalog of products, lets a cashier add items to a basket, computes totals, applies simple rules (quantity, discounts, payment and change), and prints a clear receipt. ## Functional scope (what the program must do) 1. **Product catalog**: Store a set of products, each with a name and a unit price. Use lists (and, if you wish, parallel lists or a list of small structures/dictionaries) to hold the catalog. 2. **Add items to the basket**: The user selects a product and a quantity. The item is added to the basket. The program must handle repeated additions of the same product. 3. **Browse and display the basket**: Loop through the basket and show each line (product name, quantity, unit price, line total). 4. **Compute totals**: Calculate the subtotal, an optional discount, and the final total due.
