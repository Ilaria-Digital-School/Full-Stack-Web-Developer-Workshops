# Link two pages to each other and to an external website

Theoretical recap A link is created with the a element. Its href attribute holds the destination. The text between the opening and closing tags is what the user clicks. That text must describe the destination: "See our delivery terms" is useful, "click here" is not, especially for screen-reader users who often browse a page through its list of links. Think of href as directions. An absolute URL gives the full address, including the protocol (https), and is required for any external website. A relative path gives directions starting from the folder of the current file. "about.html" means the same folder, "pages/about.html" means go down into the pages folder, and "../index.html" means go up one folder. Common mistakes include forgetting the protocol in an external link, so the browser looks for a local file that does not exist. Another is writing the path from the project root instead of from the current file. Spaces, capital letters and backslashes in file names also cause problems. Finally, opening a new tab with target="_blank" without adding rel="noopener noreferrer" is a security and privacy mistake.
