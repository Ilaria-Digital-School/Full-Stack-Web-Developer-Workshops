# Lay out a series of cards with Flexbox

Theoretical Recap Flexbox provides an efficient way to distribute space and align items within a container, even when their size is unknown or dynamic. This workshop builds directly on your recent work with flexbox alignment and navigation bars. Key definitions include the flex container (parent element with `display: flex`) and flex items (its direct children). The core mental model revolves around two axes: the main axis, defined by `flex-direction` (row or column), and the cross axis perpendicular to it. Properties like `justify-content` control alignment along the main axis, while `align-items` manages the cross axis. A common mistake is misunderstanding the `flex` shorthand property, which combines `flex-grow`, `flex-shrink`, and `flex-basis`. For example, `flex: 1 1 250px` means an item can grow and shrink equally, starting from a base width of 250px. Another frequent error is applying flex properties to child elements without first defining the container, which prevents the layout from working.
