# Refactor Factorial based

THEORETICAL RECAP A factorial of a non-negative integer n (written n!) is the product of all positive integers from 1 up to n, with the special rule that 0! equals 1. In programming, the factorial is the classic example used to compare two approaches: iteration (using a loop) and recursion (a function that calls itself). Mental model: think of factorial as a repeated multiplication that accumulates a running total. In an iterative version, you initialize an accumulator to 1, then multiply it by each value from 1 to n. In a recursive version, you express the relation factorial(n) = n * factorial(n-1), stopping at the base case factorial(0) = 1. Refactoring means improving the structure, readability, and reliability of existing code WITHOUT changing what it produces. Common mistakes include: forgetting the base case (which causes infinite recursion or a stack overflow), not handling negative inputs, duplicating logic instead of extracting a clean function, and using unclear variable names like x or temp.
