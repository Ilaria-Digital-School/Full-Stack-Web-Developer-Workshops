# Workshop: filtering and transforming a list of products

THEORETICAL RECAP In JavaScript ES6+, arrays offer powerful methods to process collections of data without manually writing loops. The three core methods are: 'filter', which returns a NEW array containing only the elements that pass a test (a callback returning true or false); 'map', which returns a NEW array where each element has been transformed by a callback; and 'reduce', which condenses an entire array into a single value (a number, an object, a string) by accumulating results. Mental model: imagine a conveyor belt of products. 'filter' is a gate that only lets certain products through. 'map' is a machine that reshapes every product that passes. 'reduce' is a bucket that collects everything into one final result. A key principle: these methods DO NOT modify the original array; they return a new one. This is called immutability and it is a best practice you already touched on in previous lessons. Common mistakes: forgetting the 'return' statement inside the callback (especially in map/filter with curly braces); confusing filter and map (filter selects, map transforms); mutating the source array; and forgetting the initial accumulator value in reduce. Mini example: const prices = [10, 25, 40]; const discounted = prices.map(p => p * 0.9); // [9, 22.5, 36] const expensive = prices.filter(p => p > 20); // [25, 40] const total = prices.reduce((acc, p) => acc + p, 0); // 75 Keep this model in mind: select, transform, aggregate.
