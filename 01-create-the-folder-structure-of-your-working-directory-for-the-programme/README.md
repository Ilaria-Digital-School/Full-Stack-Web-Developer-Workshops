# Create the folder structure of your working directory for the programme

Theoretical Recap on Organization and Structure A program is a set of instructions a computer follows, but it lives within a system of files and folders, which is how your computer organizes and stores data. Think of a well-organized physical filing cabinet as your mental model. The cabinet itself is your working directory, the top-level container. The drawers are main folders, and the files inside them are your documents, images, code, and data. Key definitions are essential. A file is a named collection of data, like a text document or a code script. A folder (or directory) is a container used to organize files and other folders. A path is the route taken through nested folders to locate a specific file, like a precise address. A directory tree is the hierarchical structure of all folders and subfolders, which you can visualize branching out from your working directory. Common mistakes include creating a flat, single-folder dump of all files, which becomes chaotic. Another is using inconsistent or unclear naming, making files hard to find. Failing to plan the structure before you start writing code leads to constant, disruptive reorganization later. Remember, a cluttered digital workspace slows you down just as much as a messy desk. Here is a small numeric example. For a basic web project, your main folder might be 'my_web_app'.
