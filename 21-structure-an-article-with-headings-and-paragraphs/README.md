# Structure an article with headings and paragraphs

Theoretical Recap HTML provides the foundational structure for web content. A well-structured article uses semantic HTML tags to create a logical hierarchy. This makes the content accessible, improves SEO, and enhances readability. Headings, from ` ` introduces the article. ` ` starts a major section. A paragraph follows: `Cats meow for various reasons...`. A subsection within that uses ` `. This creates a clean, navigable structure. Workshop Brief Your task is to write an HTML document that structures a full-length article. You will apply the semantic hierarchy of headings and paragraphs. The goal is to practice converting a plain text outline into a properly marked-up web document. This workshop tests your understanding of document flow and logical sectioning. You must create the HTML from scratch, using a text editor. The focus is solely on structure, not visual appearance. You will not use any CSS in this exercise. You are provided with the raw text content for an article. Your job is to analyze this text. Identify the main topic, the primary sections, and any subsections. Then, encode this analysis using the correct HTML heading and paragraph tags. The final deliverable is a single .html file. This file must be valid HTML5. It must render a coherent article in a web browser. The structure should be apparent from the document outline generated by the heading tags.
