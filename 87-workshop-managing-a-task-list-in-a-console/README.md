# Workshop: managing a task list in a console

THEORETICAL RECAP A task list manager in the console is a small program that stores items in memory and lets a user add, display, complete, and remove them. The core mental model is simple: your tasks live inside an array, and each task is an object with properties such as a description, a status, and possibly an id. Think of the array as a shelf and each object as a labeled box on that shelf. Your functions are the actions you perform on the shelf: put a box, read all boxes, mark a box as done, take a box away. Key definitions: an array holds an ordered collection; an object groups related data under named keys; a function encapsulates a reusable action. In ES6 you will rely on `const` and `let`, arrow functions, template literals for readable output, and array methods like `push`, `find`, `filter`, `map`, and `forEach`. Common mistakes to avoid: mutating the array in unpredictable ways, forgetting to return values from functions, comparing with `==` instead of `===`, and confusing the index of a task with its id. Another frequent error is reassigning a `const` array (you cannot reassign it, but you can modify its contents). Mini example: const tasks = []; const addTask = (text) => tasks.push({ id: Date.now(), text, done: false }); addTask('Learn JavaScript'); console.log(tasks); This creates an empty list and adds one task object.
