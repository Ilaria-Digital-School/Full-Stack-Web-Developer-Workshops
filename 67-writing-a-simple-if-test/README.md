# Writing a simple IF test

THEORETICAL RECAP A conditional test (the IF statement) allows a program to make decisions. Instead of executing instructions in a strict linear order, the program evaluates a condition — a boolean expression that is either TRUE or FALSE — and only runs a block of code when that condition is TRUE. The mental model is simple: 'IF this is true, THEN do that; OTHERWISE (ELSE), do something else.' A condition is built using comparison operators (==, !=, >, =, = 18 THEN display "You are an adult" ELSE display "You are a minor" END IF Common mistakes to avoid: confusing the assignment operator (=) with the comparison operator (==); forgetting the ELSE branch when it is needed; writing conditions that can never be TRUE or always TRUE; and mishandling data types (comparing a string with a number). Also remember that indentation and clear structure make your logic readable and debuggable. Keep conditions as simple and explicit as possible — a well-named boolean variable is often clearer than a long nested expression.
