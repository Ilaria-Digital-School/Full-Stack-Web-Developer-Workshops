# Workshop: user object and presentation method

THEORETICAL RECAP A literal object in JavaScript groups related data (properties) and behaviors (methods) inside a single structure delimited by curly braces. A property associates a key with a value (string, number, boolean, array, or even another object). A method is simply a property whose value is a function; it can act on the object's own data using the keyword 'this', which refers to the object the method belongs to. The mental model to keep in mind: an object is a labeled box where each label (key) points to a value, and some of those values are actions the box can perform on itself. Mini example: const user = { firstName: 'Sofia', lastName: 'Martin', age: 29, getFullName() { return this.firstName + ' ' + this.lastName; } }; console.log(user.getFullName()); // Sofia Martin Common mistakes to avoid: forgetting the keyword 'this' inside a method (which breaks access to the object's properties), using a comma instead of a colon between key and value, defining a method with an arrow function when you need 'this' to point to the object (arrow functions do not bind their own 'this'), and confusing dot notation (user.age) with bracket notation (user['age']). Both access the same value, but bracket notation is required when the key is stored in a variable or contains special characters.
