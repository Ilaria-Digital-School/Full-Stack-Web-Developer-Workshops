# Adapt your home page to phone screens

Theoretical Recap Responsive design ensures a website provides an optimal viewing experience across different devices. The core mental model involves fluid grids, flexible images, and media queries. A fluid grid uses relative units like percentages or fr units instead of fixed pixels, allowing layouts to resize proportionally. Flexible images are set to max-width: 100% to prevent overflow. Media queries apply different CSS rules at specific breakpoints, typically defined by screen width. A common mistake is using fixed pixel values for layout dimensions, which creates horizontal scrolling on smaller screens. Another error is placing media queries in the wrong order in the CSS; rules for larger screens should often come first, overridden by rules for smaller screens. Also, forgetting the viewport meta tag prevents proper scaling on mobile devices. Consider a container set to width: 960px. On a 375px phone, this causes scrolling. Using a fluid approach, you could set width: 90% or use a CSS Grid with 1fr. A media query like @media (max-width: 768px) { .container { width: 95%; } } adjusts the layout for tablets and phones.
