# Workshop: Click counter (prompt)

THEORETICAL RECAP Before starting the DOM, you will build a click counter using the browser's prompt() and alert() functions. A counter is simply a variable that stores a number and changes over time. The mental model is straightforward: you declare a variable initialized to zero (let count = 0;), then each time an event occurs you increase it with count++ or count += 1. Because prompt() and alert() are synchronous, you can simulate 'clicks' by asking the user, inside a loop, whether they want to click again. Key definitions: prompt(message) displays an input box and returns the typed text as a string (or null if cancelled); alert(message) shows a message; a loop (while or do...while) repeats a block until a condition becomes false. Remember that prompt() ALWAYS returns a string: 'yes' stays text, and a typed number like '5' must be converted with Number() or parseInt() before doing arithmetic. A very common mistake is writing count = count + prompt(...) which concatenates strings ('01', '011') instead of adding numbers. Mini example: let count = 0; let again = prompt('Click? (yes/no)'); while (again === 'yes') { count++; again = prompt('Click again? (yes/no)'); } alert('You clicked ' + count + ' times'); This reuses the variables, conditions and functions you practiced in previous chapters and prepares you to attach real click events to buttons later.
